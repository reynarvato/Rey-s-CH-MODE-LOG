    GitHub backup

    Everything is saved on this phone first and works with no signal. When you're online, the app copies your log, photos and a CSV for Excel into a private GitHub repo.

    How to make the token
    1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Repository access: Only select repositories → your data repo.
    3. Permissions → Repository → Contents: Read and write. Nothing else.
    4. Pick an expiry (a year is fine), generate, and paste it above.
    Import and export

    Import your old Excel log: in Excel, Save As → CSV UTF-8, then pick the file here. It needs Date, Start and End columns; Type, Quality, Exhaustion and Notes are picked up if present. Importing the same file twice won't duplicate rows.
